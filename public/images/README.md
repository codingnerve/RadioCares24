# Site photos

Add your own photos here. Each one is named after the slot it fills, so no code change is needed.
Accepted formats: `.jpg`, `.jpeg`, `.webp`, `.png`, `.avif`. Use at least 1600px on the long edge
(about 2400px is plenty). Do not bake text or provider logos into the images. Slots with no file show
a plain navy panel.

| Slot file name (without extension) | Recommended ratio | Where it appears |
| --- | --- | --- |
| `hero` | 16/9 | Home page hero (full width, navy overlay on top) |
| `service-activation` | 4/3 | Radio activation card, guide banner |
| `service-signal` | 4/3 | Signal & reception card, guide banner |
| `service-channels` | 4/3 | Missing channels card, guide banner |
| `service-subscription` | 4/3 | Subscription enquiries card, guide banner |
| `about` | 4/3 | About us page |
| `process` | 4/3 | How it works page |
| `contact` | 16/9 | Contact page |
| `banner-services` | 16/9 | Services page banner |
| `banner-how-it-works` | 16/9 | How it works page banner |
| `banner-resources` | 16/9 | Resources page banner |

Example: save a landscape photo of a dashboard as `public/images/service-channels.jpg`.
